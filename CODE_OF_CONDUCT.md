# Code of Conduct

We follow the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Read the full text at that link.

## TL;DR

- Be respectful. Disagreement is fine; harassment is not.
- Assume good faith. Ask questions before assuming malice.
- Keep it on-topic in issues and PRs.
- No spam, no self-promotion threads, no off-topic flame.

## Scope

Applies to all project spaces: GitHub issues, PRs, discussions, the wiki,
and any official chat / forum we set up.

## Enforcement

Report violations to `conduct@<repo-owner-domain>`. Reports are
confidential. The maintainer team will respond within 14 days. Consequences
range from a private warning to a permanent ban depending on severity and
pattern.
